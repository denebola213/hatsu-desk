# ADR 0003 サポートは単体採用率ではなく組み合わせで集計する

状態: 採用
決定日: 2026-11-27

## 文脈

設計 v0.1 の集計は「サポート採用率 Top N」を筆頭に置いていた。

## 決定

サポートの単体採用率を出さない。代わりに、構成タイプ（6枚のレッスン種別内訳）、ペア共起、3枚組共起、完全一致セットで見る。

## 理由

サポートは6枚のシナジーで選ばれるため、単体の出現頻度は選択理由を表さない。「よく使われる上位3枚」を知っても構成は組めない。

## 帰結

- `card_master` に `lesson_type`（Vo/Da/Vi/汎用）を持たせる。値はカード詳細画面の「スキルカードサポート」欄から取る
- 型付け・ペア集計の質はカード辞書の充足率に依存する（ADR 0004 相当の育成ループが必要）
- 完全一致セットは N=20 ではほぼ出ないので、2件以上のものだけ表示する
- 単体指標は「特定カードを含む／含まない構成のスコア中央値の差」として参考値に格下げする
