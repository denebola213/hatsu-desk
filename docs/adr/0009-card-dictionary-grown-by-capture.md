# 0009 カード辞書は同梱せず、詳細撮影で育てる

- 状態: 採用
- 日付: 2026-11-27
- 置換: なし

## 文脈

構成画面に並ぶカードはアートだけで、名前も効果も書かれていない。名前が分からなければ一覧も集計も読めない。したがってカード辞書（`card_master`）が要る。

辞書を同梱すれば照合は最初から効く。ただし同梱する中身はゲームのカード画像とテキストで、再配布になる。設計の制約（§1）は「ゲーム画像を再配布しない」「カード辞書を APK に同梱しない」と決めている。

## 決定

1. 辞書は**空の状態で出荷する**。
2. カード詳細画面を取り込むことで育てる。詳細1枚から名前・レアリティ・レッスン種別・効果文・大きなアートが同時に入る。
3. 辞書が空の間、アート照合の結果は「未詳」として保存し、集計から除外する。**未詳でも UI が破綻しないことを受入条件にする。**
4. 辞書は端末内に留める。書き出しは既定で行わない（行う場合も伏せ字を既定にする）。

## 理由

- 再配布を避ける。これは法務の判断であると同時に、ゲーム更新への追従手段でもある
- 詳細画面から名前とアートが同時に入るので、v0.1 が想定していた「未知タイルを人力で命名する」工程が不要になる（§8.5）
- 辞書をユーザーごとに育てる形にしておけば、カード追加に対してアプリの更新を待たずに追従できる

## 影響

- **初回は何も照合できない。** M0 と M1 は OCR の文字だけで成立している必要がある。アート照合は M3 以降の上乗せとして扱う
- 「未詳」の可視化が UI の要件になる（未登録の件数、辞書充足率）
- 辞書の育成は人間の操作に依存する。自動で埋める経路は作らない

## 戻す基準

公式にカード一覧の利用が許される、または辞書の共有が明示的に許される場合。そのときも、同梱ではなく取得可能な形にするかを別途判断する。
