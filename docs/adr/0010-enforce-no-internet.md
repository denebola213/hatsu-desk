# 0010 通信権限を持たないことをビルドで強制する

- 状態: 採用
- 日付: 2026-11-27
- 置換: なし

## 文脈

「端末完結」はこのアプリの約束であり、同時に規約リスクへの回答でもある（§12）。`AndroidManifest.xml` に `INTERNET` を書かなければ通信できない、という主張は、**アプリ自身の manifest を見ている限りにおいて**正しい。

問題は依存ライブラリにある。ライブラリの manifest はビルド時にマージされる。クラッシュ収集・解析・画像読み込みの類を1つ足すだけで、`INTERNET` が merged manifest に入りうる。宣言を書いていないことは、権限を持たないことの証明にならない。

## 決定

1. **merged manifest を検査する。** `scripts/check-no-internet.sh` が `aapt2 dump permissions` の出力に `android.permission.INTERNET` が無いことを確かめる。
2. **この検査をビルドの必須条件にする。** ローカルのビルドと CI の両方で走らせ、失敗したら APK を成果物にしない。
3. ソース側の `AndroidManifest.xml` だけでなく、**マージ後の成果物**を見る。

## 理由

- 宣言の有無ではなく、成果物の権限を見るのが唯一の証明になる
- 人間の注意力に依存させない。依存を1行足すだけで壊れる約束は、機械で守る
- 権限が無ければ、仮に通信のコードが混入しても実行時に失敗する。二重の担保になる

## 影響

- 通信を前提とするライブラリを追加できない（クラッシュ収集、リモート設定、解析、広告など）
- CI に1段増える。ビルドは数十秒遅くなる
- 「通信しない」を README で主張できる根拠が、意図ではなく検査になる

## 戻す基準

なし。この制約を外す判断は、この ADR を置換する ADR として行う。黙って検査を外さない。
